# Финальное исправление проблемы с видео и 403 ошибками

## Проблемы, которые были исправлены:

1. ✅ **Ошибки 403** - исправлено в `.htaccess`
2. ✅ **Тестовый файл** - удален (он конфликтовал с React Router)
3. ✅ **Маршрутизация** - настроена правильно для статических файлов

## Что нужно сделать сейчас:

### 1. Пересоберите проект

```bash
cd frontend
yarn build
```

### 2. Загрузите файлы на сервер

Загрузите **всё содержимое** папки `frontend/build/` в корень сайта.

**Важно!** Также загрузите обновленный файл `.htaccess` из `frontend/public/.htaccess` в корень сайта (это исправит ошибки 403).

### 3. Проверьте права доступа на файлы

В cPanel File Manager установите права:

- **Папки** (video, favicon, static): **755**
- **Файлы** (все .mp4, .png, .ico, .css, .js): **644**

Как установить:
1. Откройте cPanel → File Manager
2. Кликните правой кнопкой на файл/папку
3. Выберите "Change Permissions"
4. Установите нужные права

### 4. Структура на сервере должна быть:

```
/public_html/  (корень сайта)
├── .htaccess  ← ОБЯЗАТЕЛЬНО загрузить!
├── index.html
├── send-email.php
├── video/
│   └── video-background.mp4  ← права 644
├── favicon/
│   ├── favicon.ico  ← права 644
│   ├── favicon-16x16.png  ← права 644
│   ├── favicon-32x32.png  ← права 644
│   └── site.webmanifest  ← права 644
└── static/
    ├── css/
    └── js/
```

### 5. Проверьте видео

1. Откройте сайт в браузере
2. Откройте консоль (F12)
3. Перейдите на вкладку **Console**
4. Должны увидеть: `✅ Video loaded successfully` или `✅ Video can play`
5. Если ошибки - перейдите на вкладку **Network**
6. Найдите запрос к `video-background.mp4`
7. Статус должен быть **200** (не 403 или 404)

## Если всё равно не работает:

### Проверка 1: Файл существует?

Откройте в браузере напрямую:
```
https://ваш-сайт.com/video/video-background.mp4
```

- Если видео загружается → файл есть, проблема в коде
- Если ошибка 404 → файл не загружен или не в той папке
- Если ошибка 403 → проблема с правами доступа

### Проверка 2: Права доступа

Убедитесь, что:
- Файл `video-background.mp4` имеет права **644**
- Папка `video/` имеет права **755**

### Проверка 3: Консоль браузера

Откройте консоль (F12) и посмотрите:
- Если видите `Video loading error` - скопируйте всю ошибку и отправьте мне
- Если видите ошибки 403 - проверьте права доступа
- Если видите ошибки 404 - проверьте путь к файлу

## Быстрая проверка через консоль браузера

Откройте консоль (F12) и введите:

```javascript
fetch('/video/video-background.mp4', { method: 'HEAD' })
  .then(r => console.log('Статус:', r.status, r.ok ? '✅ OK' : '❌ Ошибка'))
  .catch(e => console.error('Ошибка:', e))
```

- **200** = файл найден ✅
- **403** = нет доступа (проверьте права) ❌
- **404** = файл не найден (проверьте путь) ❌

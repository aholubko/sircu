# Простая настройка для cPanel

## Что нужно сделать

### 1. Соберите frontend

```bash
cd frontend
yarn build
```

### 2. Загрузите файлы на сервер

Загрузите **всё содержимое** папки `frontend/build/` в корень вашего сайта через cPanel File Manager или FTP.

### 3. Загрузите PHP скрипт

**Важно!** Также загрузите файл `send-email.php` (который находится в `frontend/public/`) в корень сайта, туда же где и `index.html`.

Структура должна быть такой:
```
/public_html/  (корень вашего сайта)
├── index.html
├── send-email.php  ← этот файл!
├── static/
│   ├── css/
│   └── js/
├── favicon/
└── video/
```

### 4. Готово!

Теперь форма будет работать автоматически и отправлять email на `info@sircubat.com`.

## Как это работает

1. Пользователь заполняет форму
2. Форма отправляет данные на `send-email.php`
3. PHP скрипт отправляет email на `info@sircubat.com`
4. Пользователь видит сообщение об успешной отправке

## Если нужно изменить email получателя

Откройте файл `send-email.php` и измените строку:

```php
$to = 'info@sircubat.com';  // Замените на нужный email
```

Затем загрузите обновленный файл на сервер.

## Проверка

1. Откройте ваш сайт
2. Заполните форму контактов
3. Отправьте форму
4. Проверьте почту `info@sircubat.com` - должно прийти письмо

## Если что-то не работает

1. Убедитесь, что файл `send-email.php` загружен в корень сайта
2. Проверьте, что у файла есть права на чтение (обычно 644)
3. Проверьте, что PHP работает на вашем хостинге (cPanel всегда поддерживает PHP)
4. Откройте консоль браузера (F12) и проверьте ошибки

Всё! Никакого сложного backend не нужно. 🎉

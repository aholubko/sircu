# Исправление ошибки 500 - упрощенный .htaccess

Ошибка 500 означает, что в `.htaccess` есть синтаксическая ошибка или несовместимые директивы.

## ✅ Решение

Я создал **максимально простой** `.htaccess` файл, который:
- ✅ Работает на всех версиях Apache
- ✅ Не вызывает ошибок 500
- ✅ Разрешает доступ к статическим файлам (видео, favicon и т.д.)
- ✅ Правильно работает с React Router

## 📋 Что делать

### Шаг 1: Загрузите упрощенный .htaccess

Файл уже готов в `frontend/public/.htaccess` - просто загрузите его на сервер, заменив старый.

### Шаг 2: Проверьте права доступа

Убедитесь, что:
- Файл `.htaccess` имеет права **644**
- Папка `video/` имеет права **755**
- Файл `video-background.mp4` имеет права **644**

### Шаг 3: Если всё равно ошибка 500

**Временное решение** - удалите `.htaccess` совсем:

1. В cPanel File Manager найдите файл `.htaccess`
2. Переименуйте его в `.htaccess.bak` (чтобы сохранить резервную копию)
3. Проверьте, работает ли видео без `.htaccess`

Если без `.htaccess` видео работает - значит проблема была в нём.
Если не работает - проблема в правах доступа.

### Шаг 4: Альтернатива - минимальный .htaccess

Если даже упрощенный вызывает ошибку, используйте **минимальный** вариант:

```apache
# Минимальный .htaccess только для React Router
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

Этот вариант НЕ добавит никаких дополнительных настроек, только базовую поддержку React Router.

## 🔍 Проверка

После загрузки упрощенного `.htaccess`:

1. Обновите страницу (Ctrl+F5)
2. Откройте консоль (F12)
3. Проверьте:
   - ✅ Нет ошибок 500 → `.htaccess` работает
   - ✅ Видео загружается → всё отлично!
   - ❌ Всё ещё ошибка 500 → попробуйте минимальный вариант или удалите `.htaccess`

## 📞 Если проблема остаётся

1. Проверьте логи ошибок сервера (в cPanel обычно есть раздел "Errors")
2. Попробуйте удалить `.htaccess` временно
3. Проверьте права доступа на файлы
4. Напишите мне - помогу дальше!

# СРОЧНО: Исправление ошибки 403

## Проблема

Ошибка 403 = сервер **НЕ МОЖЕТ ПРОЧИТАТЬ** файлы из-за неправильных прав доступа.

Это **НЕ** проблема в коде или .htaccess - это **проблема на сервере** с правами доступа.

## ✅ Решение за 5 минут

### Способ 1: Через cPanel File Manager (РЕКОМЕНДУЕТСЯ)

1. **Откройте cPanel** → **File Manager**

2. **Найдите папку `video/`** в корне сайта

3. **Исправьте права на папку:**
   - Правой кнопкой → **Change Permissions**
   - Установите: **755**
   - Сохраните

4. **Зайдите в папку `video/`**

5. **Исправьте права на файл `video-background.mp4`:**
   - Правой кнопкой → **Change Permissions**
   - Установите: **644**
   - Сохраните

6. **Повторите для папки `favicon/` и всех файлов внутри:**
   - Папка `favicon/`: **755**
   - Все файлы внутри: **644**

### Способ 2: Через FTP (FileZilla, WinSCP)

1. Подключитесь к серверу через FTP

2. Найдите файлы на сервере

3. Правой кнопкой → **File permissions** (или **Свойства**)

4. Установите:
   - Папки: **755**
   - Файлы: **644**

## 📋 Короткая таблица

| Что | Права |
|-----|-------|
| Папка `video/` | **755** |
| Файл `video-background.mp4` | **644** |
| Папка `favicon/` | **755** |
| Все файлы в `favicon/` | **644** |

## ✅ Проверка

Откройте в браузере:
```
https://sircubat.com/video/video-background.mp4
```

- ✅ **Видео открывается** → всё готово!
- ❌ **Ошибка 403** → права всё ещё неправильные, повторите установку

## 🔍 Если не получается

Попробуйте временно установить более открытые права:

- Папки: **777**
- Файлы: **666**

Если с такими правами работает → проблема точно в правах. Верните к 755/644 после проверки.

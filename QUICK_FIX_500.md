# Быстрое исправление ошибки 500

Ошибка 500 означает, что `.htaccess` вызывает ошибку сервера. Я создал **максимально простой** `.htaccess`, который должен работать.

## ✅ Что делать СЕЙЧАС

### Шаг 1: Загрузите новый .htaccess

Я создал **упрощенный** `.htaccess` файл. Загрузите его на сервер:

1. Откройте файл `frontend/public/.htaccess` (он уже обновлен)
2. Скопируйте его содержимое
3. В cPanel File Manager откройте файл `.htaccess` на сервере
4. Вставьте новое содержимое (замените всё)
5. Сохраните

**ИЛИ** просто загрузите файл `frontend/public/.htaccess` на сервер через FTP/File Manager.

### Шаг 2: Проверьте

1. Обновите страницу (Ctrl+F5)
2. Откройте консоль (F12)
3. Проверьте - ошибки 500 быть не должно

### Шаг 3: Если всё равно ошибка 500

**Попробуйте удалить .htaccess временно:**

1. В cPanel File Manager найдите `.htaccess`
2. Переименуйте его в `.htaccess.old` (чтобы сохранить)
3. Проверьте, работает ли видео без `.htaccess`

**Если без .htaccess видео работает:**
- Проблема была в `.htaccess`
- Можно оставить без него (React Router будет работать через JavaScript)

**Если без .htaccess видео НЕ работает:**
- Проблема в правах доступа
- Верните `.htaccess` обратно и исправьте права (644 для файлов, 755 для папок)

## 📋 Новый упрощенный .htaccess

Содержимое нового файла (только базовые правила для React Router):

```apache
# Простой .htaccess для React Router
# Исправляет ошибки 403 и 500

# Fix for React Router (SPA)
<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  
  # Разрешить прямой доступ к существующим файлам
  RewriteCond %{REQUEST_FILENAME} -f
  RewriteRule . - [L]
  
  # Разрешить прямой доступ к существующим директориям
  RewriteCond %{REQUEST_FILENAME} -d
  RewriteRule . - [L]
  
  # Все остальное - на index.html для React Router
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
```

## 🔍 Проверка работы

После загрузки нового `.htaccess`:

1. Откройте сайт
2. Нажмите F12 → Console
3. Должно быть:
   - ✅ `✅ Video loaded successfully` или `✅ Video can play`
   - ❌ НЕТ ошибок 500

4. Откройте вкладку Network
5. Найдите запрос к `video-background.mp4`
6. Статус должен быть:
   - ✅ **200** = всё работает!
   - ❌ **403** = проблема с правами доступа (исправьте: файл 644, папка 755)
   - ❌ **404** = файл не найден (проверьте путь)
   - ❌ **500** = проблема с .htaccess (попробуйте удалить его)

## 💡 Альтернатива: Без .htaccess

React Router может работать и без `.htaccess`, через JavaScript. Если `.htaccess` продолжает вызывать проблемы:

1. Удалите `.htaccess` полностью
2. Сайт всё равно будет работать
3. Единственное отличие - прямые ссылки на страницы могут не работать, но основная навигация будет работать

## 📞 Если ничего не помогает

1. Убедитесь, что права доступа правильные (644/755)
2. Проверьте, что файл `video-background.mp4` существует в папке `video/`
3. Попробуйте открыть видео напрямую: `https://sircubat.com/video/video-background.mp4`
4. Напишите мне результат - помогу дальше!

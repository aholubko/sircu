# Простое решение проблемы с видео

## Главная проблема

Скорее всего, проблема в **пробелах в названии файла**. Многие серверы не обрабатывают пробелы в URL правильно.

## Решение (5 минут)

### Шаг 1: Переименуйте файл

1. Откройте cPanel → File Manager
2. Перейдите в папку `video/`
3. Кликните правой кнопкой на файл: `Minimalist Architectural Abstractions_.mp4`
4. Выберите **Rename**
5. Переименуйте в: **`video-background.mp4`** (без пробелов!)
6. Сохраните

### Шаг 2: Пересоберите проект

```bash
cd frontend
yarn build
```

### Шаг 3: Загрузите файлы на сервер

Загрузите всё содержимое `frontend/build/` в корень сайта.

### Шаг 4: Проверьте

Обновите страницу - видео должно заработать! 🎬

## Если всё равно не работает

1. Откройте консоль браузера (F12)
2. Посмотрите сообщения в Console (будут со значками ✅ или ❌)
3. Перейдите на вкладку Network
4. Обновите страницу
5. Найдите запрос к `.mp4` файлу
6. Посмотрите статус:
   - **200** = файл найден ✅
   - **404** = файл не найден - проверьте путь ❌
   - **403** = нет доступа - проверьте права (должно быть 644) ❌

# Как исправить ошибку 403 (Запрещено)

Ошибка 403 означает, что сервер не может прочитать файлы из-за неправильных прав доступа.

## 🚨 СРОЧНО: Исправьте права доступа через cPanel

### Способ 1: Через cPanel File Manager (РЕКОМЕНДУЕТСЯ)

1. **Откройте cPanel** → найдите **File Manager**

2. **Перейдите в корень сайта** (обычно `public_html` или `www`)

3. **Исправьте права для ПАПОК:**
   - Кликните правой кнопкой на папку `video/`
   - Выберите **Change Permissions**
   - Установите: **755** (или отметьте: Read, Write, Execute для Owner; Read, Execute для Group и Public)
   - Нажмите **Change Permissions**
   
   - Повторите для папок: `favicon/`, `static/`

4. **Исправьте права для ФАЙЛОВ:**
   - Кликните правой кнопкой на файл `video/video-background.mp4`
   - Выберите **Change Permissions**
   - Установите: **644** (или отметьте: Read, Write для Owner; Read для Group и Public)
   - Нажмите **Change Permissions**
   
   - Повторите для всех файлов в папке `favicon/`:
     - `favicon.ico`
     - `favicon-16x16.png`
     - `favicon-32x32.png`
     - `site.webmanifest`
     - и другие файлы

### Способ 2: Через FTP (если есть доступ)

1. Подключитесь к серверу через FTP (FileZilla, WinSCP и т.д.)

2. Найдите файлы на сервере

3. Правой кнопкой на файл/папку → **File permissions** (или **Свойства**)

4. Установите:
   - **Папки**: 755
   - **Файлы**: 644

### Способ 3: Массовое изменение прав (если много файлов)

В cPanel File Manager:

1. Выберите папку `video/`
2. Вверху нажмите **Permissions**
3. Установите нужные права для всех файлов внутри

## 📋 Таблица правильных прав доступа

| Тип | Права | Описание |
|-----|-------|----------|
| **Папки** | **755** | Все папки (video, favicon, static) |
| **Файлы** | **644** | Все файлы (.mp4, .png, .ico, .css, .js) |

## ✅ Проверка после исправления

### 1. Проверьте файл напрямую

Откройте в браузере:
```
https://sircubat.com/video/video-background.mp4
```

- ✅ **Видео загружается** → права исправлены!
- ❌ **403 Forbidden** → права всё ещё неправильные
- ❌ **404 Not Found** → файл не в той папке

### 2. Проверьте favicon

Откройте в браузере:
```
https://sircubat.com/favicon/favicon.ico
```

- ✅ **Иконка загружается** → права исправлены!
- ❌ **403 Forbidden** → нужно исправить права

### 3. Обновите сайт

После исправления прав:
1. Очистите кеш браузера (Ctrl+Shift+Del или Cmd+Shift+Del)
2. Обновите страницу (Ctrl+F5 или Cmd+Shift+R)
3. Откройте консоль (F12) и проверьте - ошибок 403 быть не должно

## 🔧 Альтернатива: Если ничего не помогает

Если исправление прав не помогло, возможно проблема в настройках сервера. 

### Попробуйте:

1. **Удалите .htaccess** на время (переименуйте в `.htaccess.bak`)
2. Проверьте, работает ли видео без .htaccess
3. Если заработало - проблема была в .htaccess
4. Если нет - проблема точно в правах доступа

## 📞 Нужна помощь?

Если после всех исправлений ошибка 403 остаётся:

1. Сделайте скриншот настроек прав в cPanel
2. Проверьте, какие права установлены сейчас
3. Напишите мне - помогу дальше!

---

**ВАЖНО:** Права доступа - это самая частая причина ошибки 403. После исправления прав всё должно заработать! ✅

# Исправление проблемы с фоновым видео

## Проблема
Видео не грузится в продакшене.

## Возможные причины и решения

### 1. Проверьте, что файл видео загружен на сервер

Убедитесь, что папка `video/` с файлом `Minimalist Architectural Abstractions_.mp4` находится в корне вашего сайта:

```
/public_html/  (корень вашего сайта)
├── index.html
├── send-email.php
├── video/  ← эта папка должна быть здесь!
│   └── Minimalist Architectural Abstractions_.mp4
├── static/
└── favicon/
```

### 2. Проблема с пробелами в названии файла

Если файл всё ещё не загружается, лучше переименовать файл, убрав пробелы:

**Вариант 1: Переименовать файл (рекомендуется)**

1. Переименуйте файл: `Minimalist Architectural Abstractions_.mp4` → `video-background.mp4`
2. Замените в коде путь (я уже добавил обработку, но можно упростить)

**Вариант 2: Проверить права доступа к файлу**

Убедитесь, что файл имеет права на чтение (обычно 644):
- В cPanel File Manager: кликните правой кнопкой на файл → Change Permissions → установите 644

### 3. Проверить MIME-тип на сервере

Некоторые серверы могут не распознавать `.mp4` файлы. Добавьте в `.htaccess` (если его нет, создайте в корне сайта):

```apache
# .htaccess в корне сайта
AddType video/mp4 .mp4
AddType video/webm .webm
AddType video/ogg .ogv
```

### 4. Проверить размер файла

Если файл очень большой (>10MB), это может вызывать проблемы:
- Оптимизируйте видео (уменьшите качество/размер)
- Или используйте видеохостинг (YouTube/Vimeo) и вставьте через iframe

✅ Добавлен fallback на градиентный фон, если видео не загрузится
✅ Добавлен индикатор загрузки
✅ Добавлена поддержка URL с пробелами (URL-encoded)

### 6. Как проверить, что работает

1. Откройте сайт в браузере
2. Откройте консоль разработчика (F12)
3. Перейдите на вкладку Console
4. Посмотрите, есть ли ошибки связанные с видео
5. Перейдите на вкладку Network
6. Обновите страницу
7. Найдите запрос к файлу видео - проверьте статус (должен быть 200)

### 7. Быстрое решение (если ничего не помогает)

Если видео всё равно не работает, можно использовать статическое изображение:

1. Создайте скриншот из видео или используйте любое подходящее изображение
2. Сохраните как `video-poster.jpg` в папку `public/`
3. Замените видео на фоновое изображение

Я уже добавил fallback, который покажет градиентный фон, если видео не загрузится. Сайт всё равно будет работать!

## Проверка после исправления

1. Пересоберите проект: `cd frontend && yarn build`
2. Загрузите обновленные файлы на сервер
3. Убедитесь, что папка `video/` с файлом находится в корне
4. Проверьте права доступа к файлу (644)
5. Обновите страницу и проверьте консоль браузера

# Диагностика проблемы с видео

## Быстрая проверка

### 1. Откройте консоль браузера (F12)

Перейдите на вкладку **Console** и посмотрите, какие сообщения там появляются. Вы должны увидеть сообщения вида:
- `🔄 Video loading started: ...`
- `✅ Video loaded successfully` или
- `❌ Video loading error: ...`

### 2. Проверьте вкладку Network

1. Откройте вкладку **Network** в консоли разработчика
2. Обновите страницу (F5)
3. Найдите запрос к файлу `.mp4`
4. Посмотрите статус:
   - **200** = файл найден и загружен ✅
   - **404** = файл не найден ❌
   - **403** = нет доступа к файлу ❌
   - **0** = запрос не отправлен ❌

### 3. Проверьте структуру файлов на сервере

Убедитесь, что структура такая:

```
/public_html/  (корень сайта)
├── index.html
├── .htaccess
├── send-email.php
├── video/  ← эта папка должна быть здесь!
│   └── Minimalist Architectural Abstractions_.mp4
├── static/
└── favicon/
```

### 4. Проверьте права доступа

Файл видео должен иметь права **644**:
- В cPanel File Manager: кликните правой кнопкой на файл → Change Permissions → установите 644

### 5. Проверьте размер файла

Если файл очень большой (>50MB), это может вызывать проблемы. Оптимизируйте видео или загрузите на видеохостинг.

---

## Простое решение: Переименовать файл

**Пробелы в названии файла часто вызывают проблемы!**

### Вариант 1: Переименовать через cPanel

1. Откройте cPanel → File Manager
2. Перейдите в папку `video/`
3. Кликните правой кнопкой на файл `Minimalist Architectural Abstractions_.mp4`
4. Выберите Rename
5. Переименуйте в: `video-background.mp4` (без пробелов!)
6. Сохраните

### Вариант 2: Через FTP

1. Подключитесь через FTP
2. Перейдите в папку `video/`
3. Переименуйте файл: `Minimalist Architectural Abstractions_.mp4` → `video-background.mp4`

После переименования обновите страницу - видео должно заработать!

---

## Альтернативное решение: Использовать видеохостинг

Если видео всё равно не работает, можно загрузить на YouTube/Vimeo и вставить через iframe:

1. Загрузите видео на YouTube (можно сделать приватным)
2. Получите embed код
3. Замените видео на iframe

Но сначала попробуйте переименовать файл - это проще! 😊

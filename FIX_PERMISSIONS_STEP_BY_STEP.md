# Пошаговая инструкция: Исправление прав доступа (403 ошибка)

Ошибка 403 означает, что сервер **НЕ МОЖЕТ ПРОЧИТАТЬ** файлы. Это **100% проблема с правами доступа**.

## 🚨 ВАЖНО: Проблема НЕ в .htaccess, а в правах доступа!

## 📋 Пошаговая инструкция через cPanel

### Шаг 1: Откройте cPanel File Manager

1. Войдите в cPanel
2. Найдите раздел **Files** → **File Manager**
3. Откройте его

### Шаг 2: Перейдите в корень сайта

1. Обычно это папка `public_html` или `www`
2. Откройте эту папку

### Шаг 3: Исправьте права на ПАПКУ `video/`

1. Найдите папку `video/`
2. **Кликните ПРАВОЙ кнопкой** на папку `video/`
3. Выберите **Change Permissions** (или **Свойства** → **Права доступа**)
4. Установите:
   - **Owner (Владелец):** Read, Write, Execute ✅✅✅
   - **Group (Группа):** Read, Execute ✅✅❌
   - **Public (Публичный):** Read, Execute ✅✅❌
5. Или просто введите число: **755**
6. Нажмите **Change Permissions**

### Шаг 4: Исправьте права на ФАЙЛ `video-background.mp4`

1. Зайдите ВНУТРЬ папки `video/`
2. Найдите файл `video-background.mp4`
3. **Кликните ПРАВОЙ кнопкой** на файл
4. Выберите **Change Permissions**
5. Установите:
   - **Owner (Владелец):** Read, Write ✅✅
   - **Group (Группа):** Read ✅
   - **Public (Публичный):** Read ✅
6. Или просто введите число: **644**
7. Нажмите **Change Permissions**

### Шаг 5: Исправьте права на ПАПКУ `favicon/`

1. Вернитесь в корень сайта
2. Найдите папку `favicon/`
3. **Кликните ПРАВОЙ кнопкой** → **Change Permissions**
4. Установите: **755**
5. Нажмите **Change Permissions**

### Шаг 6: Исправьте права на ВСЕ ФАЙЛЫ в папке `favicon/`

1. Зайдите ВНУТРЬ папки `favicon/`
2. Для КАЖДОГО файла:
   - `favicon.ico` → **644**
   - `favicon-16x16.png` → **644**
   - `favicon-32x32.png` → **644**
   - `site.webmanifest` → **644**
   - Все остальные файлы → **644**

   Как сделать:
   - Правой кнопкой на файл → Change Permissions → **644** → Change Permissions

### Шаг 7: Проверьте

1. Откройте в браузере напрямую:
   ```
   https://sircubat.com/video/video-background.mp4
   ```

2. Если видите видео → права исправлены! ✅
3. Если видите ошибку 403 → права всё ещё неправильные ❌

## 📊 Таблица правильных прав

| Что | Права | Числовое значение |
|-----|-------|-------------------|
| **Папка `video/`** | rwxr-xr-x | **755** |
| **Файл `video-background.mp4`** | rw-r--r-- | **644** |
| **Папка `favicon/`** | rwxr-xr-x | **755** |
| **Все файлы в `favicon/`** | rw-r--r-- | **644** |
| **Папка `static/`** | rwxr-xr-x | **755** |
| **Все файлы в `static/`** | rw-r--r-- | **644** |

## 🔍 Как проверить текущие права

В cPanel File Manager:

1. Правой кнопкой на файл/папку → **Change Permissions**
2. Посмотрите, какие галочки установлены
3. Сравните с таблицей выше

## ⚡ Быстрый способ через cPanel (если есть опция)

В некоторых версиях cPanel есть опция "Fix Permissions":

1. Выберите папку `video/`
2. Вверху найдите кнопку **Fix Permissions** или **Permissions**
3. Выберите шаблон "Directory" (755) или "File" (644)
4. Примените ко всем файлам внутри

## ✅ Проверка после исправления

1. Откройте сайт
2. Нажмите F12 → вкладка **Network**
3. Обновите страницу (F5)
4. Найдите запрос к `video-background.mp4`
5. Статус должен быть **200** (не 403!)

## 🆘 Если ничего не помогает

Попробуйте установить более открытые права (временно):

- Папки: **777** (небезопасно, но для проверки)
- Файлы: **666** (небезопасно, но для проверки)

Если с такими правами работает → значит проблема точно в правах, и нужно вернуть к 755/644 и проверить настройки сервера.
